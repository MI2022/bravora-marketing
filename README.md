# Bravora Marketing Site

Static marketing site for [gobravora.com](https://gobravora.com).

Deployed via Cloudflare Pages as a **separate project** (`bravora-marketing`) from the receiving-page app (`bravora-receiving`).

## Structure

```
index.html   — full marketing landing page
```

## Deploy

```bash
npm run deploy
```

Or push to `main` if the Cloudflare Pages project is connected to this repo via the dashboard.
